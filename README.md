# StudyBoard

StudyBoard is a web application designed to help students organize their studies and manage learning tasks.

## Team

Built by **MrLudrik and the StudyBoard team**.

## Technologies

* React
* TypeScript
* Vite
* CSS

## Requirements

* [Node.js](https://nodejs.org/)
* npm

## Getting Started

1. Clone the repository.

2. Install dependencies:

   ```bash
   npm ci
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Build

To build the application for production:

```bash
npm run build

```

## Team Workflow

* Each team member works on their own branch.
* Use descriptive branch names.
* Commit changes regularly.
* Merge changes into the main branch through pull requests.

**Important:** Do not work directly on the `main` branch.
